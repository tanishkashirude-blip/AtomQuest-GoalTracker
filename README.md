## 📌 Problem Statement
GoalTrack is a structured, digital Goal Setting & Tracking Portal that supports the full lifecycle of employee goals — from creation and approval to quarterly check-ins and performance visibility.

## ✅ Features
- All 3 roles: Employee, Manager, Admin
- Goal creation with weightage validation
- Manager approval workflow
- Quarterly actuals tracking
- Completion Dashboard
- Reports & CSV Export
- Audit Trail
- Cycle Management
- Share KPI

## 🏗️ Tech Stack
- Frontend: React, TypeScript, Tailwind CSS
- Backend: Node.js, Express.js
- Hosting: Replit
